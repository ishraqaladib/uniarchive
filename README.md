# UniArchive landing page

Responsive landing page based on page 1 of the supplied UI design and the landing-page requirements in the SRS. Open `dist/index.html` directly, or serve `dist` using a static HTTP server.

Includes persistent light/dark mode, animated illustrative counters, responsive navigation, plan previews, help FAQs, and accessible login/signup preview dialogs with password confirmation. Account creation, authentication, uploads, billing, and emails require the full application backend and are not implemented by this landing page. Sample statistics and prices are identified in the interface.

Source: `dist/index.html`, `dist/styles.css`, `dist/app.js`. No build or dependency installation required.
